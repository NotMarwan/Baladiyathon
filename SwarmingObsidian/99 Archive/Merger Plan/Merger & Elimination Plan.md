## 2) مبدأ الدمج (لماذا الدمج أقوى من الاختيار)

كل مشروع نهائي = **محرّك مُثبت** (واقعية + مصادر) + **أفضل عرض مبهر** (يكسب معيار العرض) + **أقوى مُميّز** (يكسب معيار الابتكار). هكذا نحلّ توتّرك القديم: الواقعية والانبهار في مشروع واحد.

## 3) المشاريع الرائدة الثلاثة (بعد الدمج)

### 🥇 أثر (Athar) — التحدي 3 — **الترشيح الأول**
> يدمج: **أثر** (المحرّك) + **حفرة/HAFRA** (المُميّز) + **مرآة المدينة/MIR'AT** (العرض)

- **المحرّك الواقعي [من أثر]:** درجة أثر مروري قبل التصريح · محاكاة SUMO · مُحسِّن الجدولة · خطة إدارة مرور عربية.
- **المُميّز [من حفرة]:** ذكاء اصطناعي **داخل حلقة الموافقة** + دمج/إعادة جدولة الحفريات المتضاربة في خنادق مشتركة.
- **العرض المبهر [من مرآة المدينة]:** توأم رقمي بشريط زمن — ترسم إغلاقاً، تسحب الساعات، أحمر ← أخضر.
- **الأصل المُثبت:** UK Street Manager + بحث محكّم (−11.1%) + Dig Once.

### 🥈 رقيب (Raqib) — التحدي 2
> يدمج: **الرقيب الاستباقي** (المحرّك) + **راصد بلادي/نذير** (طبقة الأقمار — **بدون درون**) + **بصيرة** (التنبيه الاستباقي)

- **المحرّك الواقعي [من الرقيب]:** نموذج تقييم خطورة المخالفات (مُثبت — نموذج شيكاغو 69% مقابل 55%) · قائمة تفتيش مرتّبة · قابل للتفسير.
- **الإضافة [من راصد/نذير]:** كشف تغيّر بالأقمار (Sentinel-2) للبناء بلا ترخيص — **قابل للنشر وآمن قانونياً**.
- **المُميّز [من بصيرة + الرقيب]:** **تنبيه عربي استباقي للمالك قبل المخالفة** + عدالة بالتصميم (نُقيّم أماكن لا أشخاص).
- **العرض المبهر:** شريط قمر قبل/بعد يكشف مبنى جديداً بلا تصريح → تنبيه تلقائي + مقارنة back-test.
- ⚠️ **قرار إقصاء حاسم:** **حذف طبقة الدرون بالكامل** (لغم خصوصية + تصريح GACA). نُبقي الأقمار فقط.

### 🥉 مُطابِق (Mutabiq) — التحدي 1
> يدمج: **مُطابِق** (المحرّك) + **مراقب/Muraqqib** (خريطة الدبوس) + لمسة بصرية من **تخيّل**

- **المحرّك الواقعي [من مُطابِق]:** استيعاب اللوائح بالذكاء (نص←قاعدة) · OpenFisca · حكم قابل للتفسير + البند.
- **الإضافة [من مراقب]:** خريطة «ضع دبوساً» — امتثال أخضر/أحمر حسب الموقع + أثر تراكمي.
- **العرض المبهر [من مُطابِق + تخيّل]:** اختر نشاطاً + ضع دبوساً → حكم فوري لكل اشتراط بالبند؛ ثم حوّل فقرة لائحة عربية إلى قاعدة حيّة.
- **الأصل المُثبت:** OpenFisca (حكومة NSW) + Archistar (55%/90%).

## 4) قائمة الإقصاء (ماذا حُذف ولماذا)

| المشروع | القرار | السبب |
|---|---|---|
| ترخيص (Tarakkhus) | 🔀 دُمج في مُطابِق | نسخة أضعف من نفس الجوهر |
| مراقب (Muraqqib) | 🔀 دُمج في مُطابِق | خريطته = واجهة مُطابِق |
| تخيّل (Takhayyal) | ✂️ لمسة بصرية فقط | ادعاء «موافقة 90 ثانية» غير واقعي — يُحذف |
| حفرة (HAFRA) | 🔀 دُمج في أثر | مُنسّق الحفريات = مُميّز أثر |
| مرآة المدينة (MIR'AT) | 🔀 دُمج في أثر | توأمها = عرض أثر |
| حراس (HURAS) | ❌ حُذف | خارج التحدي + درون |
| نذير (NADHEER) | ✂️ الأقمار فقط | الدرون لغم خصوصية — يُحذف؛ الأقمار → رقيب |
| راصد بلادي | 🔀 طبقة الأقمار → رقيب | الدرون يُحذف |
| بصيرة (Baseera) | 🔀 التنبيه الاستباقي → رقيب | التعلّم الفيدرالي غير قابل للعرض — يُحذف |
| منشآت Guardian | 🔀 دُمج في رقيب | طبقة التفسير |
| Balady Twin | ❌ كمشروع · ✅ كسردية | توأم كامل غير قابل للعرض — يُعاد استخدام قصته أدناه |

**النتيجة: 15 مفهوماً ← 3 مشاريع رائدة + سردية موحّدة.**

## 5) السردية الموحّدة (تأطير، ليست مشروعاً رابعاً)
**«طبقة ذكاء بلدي»** — المشاريع الثلاثة = ثلاث وحدات لطبقة ذكاء واحدة فوق بلدي (امتثال ← تفتيش ← بنية تحتية) تتشارك API الامتثال. هذه **قصة العرض/الموضعة**، وليست بناءً منفصلاً. (بهذا نستعيد قيمة «Balady Twin» بلا مخاطرة بنائه.)
