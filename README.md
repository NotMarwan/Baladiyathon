# مسار (Masar) — بلدياثون 2026، التحدي الثالث

تقييم أثر الحفريات على الحركة المرورية **قبل** إصدار التصريح، وجدولة الأعمال، وتنسيق الحفر الموحّد (dig-once).

> **اسم المشروع هو «مسار».** أي ملف يسمّيه «أثر» فهو من مرحلة سابقة ومكانه `_archive/athar-era/`. لا تبنِ عليه.

---

## تشغيل في ٦٠ ثانية

```bash
node presentation/server.js
```

ثم افتح `http://localhost:8734/`. نقطة الدخول للمحكّم: **مكتب المراجع** — ١٥٠ تصريحاً على شوارع رياض حقيقية.

```bash
npm test
```

٧٧ حزمة · ١٢٧٨ فحصاً. هذه بوابة القبول: أي تغيير يجب أن يبقيها خضراء.

## قواعد التنقل للوكلاء

**١. الرسم أولاً، نظام الملفات ثانياً.**

```bash
graphify query "كيف يحسب مسار درجة التأثير المروري؟"   # جواب مع المصادر
graphify path "Masar" "SUMO"                            # أقصر مسار بين مفهومين
graphify explain "BPR Score"                            # شرح عقدة
graphify update                                         # إعادة الفهرسة بعد التعديل
```

اسأل الرسم لتحديد المجتمع والملفات، ثم افتح تلك الملفات وحدها. لا تمشِ في الشجرة عشوائياً.

**٢. لا تقرأ `_archive/`.** محتواه أفكار مُقصاة وتصاميم استُبدلت وتقييمات من مرحلة «أثر». قراءته تنتج قرارات مبنية على واقع منتهٍ.

**٣. الحساب له مصدر واحد.** كل رقم مروري يخرج من `presentation/masar-engine.js`. لا تُعِد اشتقاق معادلة في مكان آخر.

**٤. قاعدة الدليل.** صنّف كل رقم: مُثبَت عملياً، مُتحقَّق خارجياً، متوقَّع من تجربة، أو سيناريو توسّع مشروط. الادعاء بلا مصدر يُخصم في التحكيم.
