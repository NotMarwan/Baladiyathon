## ترتيب الدمج في main (يقلل التصادم)

1. `crit35-quality` (تغييرات صغيرة، أساس اختبارات السلامة).
2. `crit2-innovation` (ملفات جديدة فقط — صفر تصادم متوقع).
3. `crit6-pitch` (ملفات عرض لا يلمسها أحد آخر — صفر تصادم).
4. `crit4-impact` (engine + prototype بطاقات).
5. `crit1-challenge` (prototype خريطة — أكبر احتمال تصادم مع 4 في prototype: يحل المنسق يدوياً؛ مناطقهما مفصولة وظيفياً).

## بوابة القبول قبل دمج أي فرع (يفحصها المنسق عدائياً)

- `node presentation/tests/engine-test.js` + `ui-smoke-test.js` + اختبارات الفرع الجديدة — الكل أخضر.
- متصفح `file://`: صفر أخطاء console، التدفق كامل.
- فحص الفخاخ الثلاثة: إشارة الأرقام، لا نجاح مضمون بالتصميم، وسم كل تركيبي.
- فحص الممنوعات + كل رقم ضد `source-ledger.json`.
- `REPORT.md` موجود بدرجة ذاتية ≥9.0 وأدلة.
- **الدرجة المعتمدة يعطيها المنسق لا المنفذ** — درجة ذاتية ≥9.0 شرط دخول التقييم لا نتيجته.

## تنبيهات تصادم معروفة (مقصودة، تُحل عند الدمج)

- إصلاح إشارة CO₂ (crit4) سيعيد ربط أسطر أضافها crit35 في renderScore — قرار الدمج: منطق crit4 يفوز، وسم crit35 يبقى.
- `WORK_WINDOW_HOURS` صُدّر من engine في crit35 — لو عدّل crit4 كائن التصدير، دمج نصي بسيط.
- ادعاءات «يقيس جدواها/على الشبكة» في ملفات GPT 1: تُحدَّث بعد دمج crit1 إن اكتملت قدرة التوجيه الفعلية — خطوة منسق نهائية.
