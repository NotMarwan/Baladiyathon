# خطة ChatGPT — رفع المعيار 6 (العرض التقديمي 7.5→9.5) والمعيار 2 (الابتكار 7.5→9.0+)

> **للمنفذ (ChatGPT):** هذه خطة نصية/HTML بحتة. لا تحتاج تشغيل خادم ولا Node. كل مهمة فيها: مرساة نصية دقيقة (نص موجود في الملف تبحث عنه)، والمحتوى الكامل الجاهز للإدراج، وفحص قبول نصي. نفّذ المهام بالترتيب. لا تلخص ولا تعد صياغة المحتوى المعطى — أدرجه كما هو.

**Goal:** حقن قاعدة الأدلة السعودية الرسمية (بحث 2026-07-23) في ملفات العرض الثلاثة، وإضافة شريحة منافسين عالمية بتميّز مُدافَع عنه، وإعادة تأطير الابتكار كخمس حلقات، وتجهيز أجوبة أسئلة اللجنة.

**Architecture:** ثلاثة ملفات HTML عرض (شرائح وثائقية، ليست تطبيقاً) تُعدَّل نصياً. المراسي نصوص فريدة موجودة اليوم في الملفات — ابحث عن النص الحرفي ثم أدرج قبله أو بعده حسب التعليمة.

**Tech Stack:** HTML/CSS عربي RTL قائم. لا JS جديد. لا مكتبات.

## Global Constraints (اقرأها قبل أي تعديل)

- **تقسيم الملفات (صارم):** تعدّل فقط: `presentation/athar-pitch.html` · `presentation/athar-merged.html` · `presentation/athar.html`. **ممنوع لمس** `athar-engine.js` / `athar-prototype.html` / `tests/` (ملكية كلود — تعديل متوازٍ جارٍ فيها).
- **الممنوعات الحمراء (تصفير المعيار عند الخرق):**
  - لا رقم لعدد التصاريح السنوية (لا 10,000 ولا أي تقدير) — لا يوجد رقم رسمي منشور.
  - لا مجاميع وطنية («ملايين الساعات على مستوى المملكة») — أي توسع يُذكر كسيناريو مشروط فقط.
  - لا «أول منصة» / «غير مسبوق» / «لا يوجد حل مشابه» — سنغافورة وone.network موجودان.
  - لا نسبة ازدحام المدينة كله إلى الحفريات — الأرقام العامة «سياق بيئة» والمنفعة «تأخير منسوب للعمل» فقط.
  - كل رقم جديد يُدرج مع مصدره وتاريخه في الموضع نفسه.
- **قاعدة الشريحة:** ادعاء واحد + رقم واحد + مصدر واحد + حد استخدام واحد.
- **الأسلوب:** حافظ على بنية CSS القائمة (`class="stat"`, `class="num"`, `class="lab"`, `class="ref"` في pitch/merged/athar). أدرج ضمن الأنماط الموجودة، لا تخترع أنماطاً جديدة.
