## الحارس السببي — محاولات إجبار مباشرة

المثال التركيبي كما هو مسلَّم:

```
0 as shipped   causal=false
  «الحزمة تركيبية. المثال التركيبي لاختبار الاستيراد ولا يُحسب منه أثر مهما اكتمل.»
```

ثلاث محاولات للالتفاف — كلها فشلت:

| المحاولة | النتيجة |
|---|---|
| حذف علامة التركيب من الجذر + `source: 'field'` | `allowed: false` — الحارس يقرأ `study.study.synthetic` لا الجذر |
| ترقية التصميم إلى `before-after-control-impact` | `allowed: false` — الشرط التركيبي يسبق فحص التصميم |
| الاثنان معاً | `allowed: false` |

**الادعاء السادس عشر ثبت كما هو مسلَّم.** الحزمة المرفقة لا تدخل حكم الأثر.

### قيد بنيوي — F8

الحارس يقرأ **علماً معلَناً**:

```js
if (study && study.study && study.study.synthetic) { return { allowed: false, … }; }
```

قلبُ `study.synthetic` إلى `false` يدوياً يفتح الباب فوراً:

```
A study.synthetic := false          causal=true   «تصميم «محور مقارنة» معلن ومكتمل الشروط.»
B study.synthetic deleted           causal=true
D flag off + DiD + fabricated control  causal=true
```

هذا ليس عيباً في الحماية من الاستيراد العرضي — العلم موجود ويعمل. لكنه يعني
أن الحماية **إقرارية لا استدلالية**: لا يوجد فحص يكشف بيانات مولَّدة من
خصائصها. لا يُطلب حلّه اليوم، لكن يجب ألا يُعرض بوصفه ضماناً أقوى مما هو.

### تقييم

**تُمسَك فعلاً** (11 من 16): غياب فترة قبل أو أثناء، فترات فارغة، أوقات
متداخلة، ترتيب زمني مقلوب، غياب المنطقة الزمنية، مصدر حجم مجهول، مصادر
فارغة، نصيب عيّنات فاشل، قيم خارج المدى الفيزيائي، تصميم مقارنة معلن بلا
سلسلة مقارنة.

**تمرّ بلا اعتراض حاسم** (ثلاث):

1. **غياب فترة «بعد»** — غير مطلوبة في `REQUIRED_PATHS`. مبرَّرة جزئياً
   (تصاميم قبل/أثناء موجودة)، لكن التكليف يعدّها حالة يجب أن تُرصد.
2. **`coverage = 0`** — تحذير لا فشل. اختيار تصميمي مقبول، لكن تغطية صفرية
   على كل عيّنة أقرب إلى عطل منها إلى تحذير.
3. **`confounders = []`** — **تمرّ صامتة**. وهذه أهمها: «أحداث مربكة غير
   معلنة» هي بالضبط ما يفسد تفسير فرق قبل/بعد، ولا يوجد فحص يفرّق بين «لا
   مُربِكات» و«لم يُسأل أحد عنها».

## هل تُمنح نقاط أثر لوجود الحزمة؟

**لا.** ثلاثة أدلة:

1. لا حالة ميدانية واحدة في المستودع (`fieldCases = 0`).
2. المثال الوحيد تركيبي ومرفوض من الحارس.
3. الحزمة تقول ذلك بنفسها: «وجودها ليس دليلاً… البنية التحتية الجاهزة لا
   ترفع درجة الأثر المثبت — ترفع فقط سرعة الاستفادة من أول حالة تصل.»

## حارس الصياغة

`checkPhrasing()` فُحص مستقلاً على ثلاث عبارات:

| النصّ | النتيجة |
|---|---|
| «الإغلاق **تسبب** في زيادة التأخير 30٪» | ❌ مرفوض — «ادّعاء سببي بلا حالة مقابلة» |
| «**أثبتنا** **أثر الإغلاق** ميدانياً» | ❌ مرفوض — مخالفتان |
| «فرق مرصود مرتبط زمنياً بالعمل» | ✅ مقبول |

الحارس يعمل، ويقترح الصياغة البديلة المسموحة بدل الرفض المجرَّد.

## الحكم

الحزمة **حقيقية وتعمل**، لا هيكلاً معروضاً. فحوصها تمسك أغلب ما يجب أن
تمسكه، وحارسها السببي يصمد أمام محاولات الالتفاف المباشرة. وثلاث ثغرات
مسجَّلة أعلاه، أهمها المُربِكات الفارغة.

**صفر نقاط أثر ميداني.** الحزمة استعداد لا دليل، وهي تقولها بنفسها.
