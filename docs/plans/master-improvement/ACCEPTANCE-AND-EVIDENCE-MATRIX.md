# Acceptance and Evidence Matrix — «مسار»

قاعدتان تحكمان هذا الجدول:

1. **لا يُقبل فحص نصّي (`grep` / `indexOf` / وجود كلمة) دليلاً على سلوك.** يُقبل فقط دليلاً على **غياب** نص (تطهير الادعاءات، بوابات الاتساق) — وهذا استعماله الصحيح الوحيد.
2. **كل اختبار قبول يجب أن يفشل عمداً قبل الإصلاح.** اختبار يمرّ قبل الإصلاح وبعده لا يثبت شيئاً. عمود «الفشل المزروع» هو العمود الحاكم.

## قاعدة الأدلة عند التسليم

كل حزمة منجَزة تُرفق:

1. **أمر التشغيل** حرفياً كما يُنفَّذ.
2. **إخراجه** كما هو، لا ملخّصاً.
3. **الفشل المزروع** قبل الإصلاح — أو تصريح مكتوب بأنه لم يُزرع ولماذا.
4. **لقطة عند 1440 ولقطة عند 390** لكل تغيير مرئي.

بند بلا هذه الأربعة يُعدّ **غير منجَز**، مهما بدا الكود صحيحاً.
