## البرومبت

```
دورة رفع درجة — مشروع مسار. اقرأ docs/plans/score-loop/LOOP-DESIGN.md ثم CYCLE-LEDGER.md وتابع من آخر سطر.

الجذر الوحيد المسموح بالكتابة فيه: C:/Users/wasan/Downloads/Swarm/masar-loop
الهدف: ٩ في كل معيار من الستة، بتحكيم بارد لا بتقدير ذاتي.

نفّذ الدورة بأطوارها:
٠ · تموضع: git status هنا وفي الشجرة الرئيسية. إن تقدّم main فوفّق فرعي عليه.
١ · خطّط: من قائمة الرفع في آخر تحكيم، اختر ٢–٣ حزم بأعلى (نقطة مكتسَبة ÷ ساعة)،
     بملكية ملفات متقاطعة الصفر، والظاهري قبل الباطني، والأسهل قبل الأصعب.
٢ · نفّذ: وكيل فرعي لكل حزمة، بمسارات مطلقة وحدود صريحة وملفات ممنوعة مسمّاة.
     لا وكيل يشغّل الحزمة الكاملة، ولا يلتزم في شجرة غير هذه، ولا يوقف عملية ليست له.
٣ · تحقّق: أنا وحدي أشغّل npm test. أخضر أم تُرَدّ الحزمة. ولكل ادعاء رفعٍ:
     اختبار يؤكّده + زرعُ فشلٍ متعمَّد يُسقِطه + إزالة الزرع وإعادة الأخضر.
٤ · احكم: كل ثلاث دورات، أو فور اكتمال معيار — ثلاث حقائب عمياء، ومن نفّذ لا يحكم.
٥ · راجع: اكتب الدلتا بإيصالها في CYCLE-LEDGER.md. دلتا بلا إيصال ليست دلتا.

قواعد لا تُخرَق:
- UNVERIFIED = فشل، لا تأجيل.
- بنية تحتية لم تُشغَّل ببيانات حقيقية ترفع السقف لا الدرجة.
- رقم بلا تصنيف مصدر ممنوع. رقم مزروع يتظاهر بأنه محسوب ممنوع.
- لا كتابة خارج هذه الشجرة. لا force. لا حذف تاريخ. لا لمس شجرة وكيل آخر.
- الدمج في main فقط حين تكون شجرته نظيفة والفرع أخضر وبلا تعارض.
- معيار الأثر محكوم بسقف خارجي (صفر حالة ميدانية): ابلغ أقصاه داخل المستودع
  ثم أعلن السقف صراحةً. لا ترفعه تجميلاً.

ثم قرّر: دورة أخرى أم توقّف؟ توقّف إن بلغت الستة ٩ عند حقيبتين، أو مرّت دورتان
بلا دلتا موجبة مثبتة، أو تعذّر إبقاء الأخضر. غير ذلك: جدوِل الاستيقاظ التالي واستمر.
```
