# خرائط تجربة المستخدم

## رحلة المراجع الكاملة

```mermaid
flowchart TB
  A["فتح صندوق الأعمال"] --> B["اختيار عمل يحتاج قرارًا"]
  B --> C["تركيز الخريطة وفتح ملف العمل"]
  C --> D{"هل البيانات مكتملة؟"}
  D -- "لا" --> E["تحديد النواقص ومصدر كل حقل"]
  E --> F["إرجاع الطلب"]
  F --> A
  D -- "نعم" --> G["حساب الأساس والأثر"]
  G --> H["كشف التعارض وفرص التعاون"]
  H --> I{"هل الأثر عال أو الثقة منخفضة؟"}
  I -- "نعم" --> J["إحالة لمحاكاة متخصصة أو مراجعة خبير"]
  J --> K["استلام مؤشرات السيناريو"]
  I -- "لا" --> L["ترتيب أفضل ثلاثة بدائل"]
  K --> L
  L --> M["مراجعة الأسباب والقيود"]
  M --> N["تحرير مسودة خطة المرور"]
  N --> O{"القرار"}
  O -- "إرجاع" --> F
  O -- "رفض" --> P["تسجيل سبب الرفض"]
  O -- "اعتماد" --> Q["تثبيت النسخة والجدول"]
  Q --> R["نشر الإغلاق للقنوات"]
  R --> S["مراقبة التنفيذ"]
  S --> T["إغلاق العمل"]
  T --> U["مقارنة المتوقع بالمرصود"]
  U --> V["تحديث سجل المعايرة"]
```

## الرحلة بين الجهات

```mermaid
sequenceDiagram
  participant Applicant as مقدم الطلب
  participant Permit as منصة التصريح
  participant Masar as أثر
  participant Reviewer as المراجع
  participant Partner as جهة متعارضة
  participant Channel as قناة النشر
  participant Field as الميدان

  Applicant->>Permit: إرسال الطلب
  Permit->>Masar: بيانات الطلب والهندسة
  Masar->>Masar: فحص الأثر والتعارض
  Masar-->>Reviewer: بدائل مرتبة وأسباب
  alt توجد فرصة تعاون
    Reviewer->>Partner: دعوة تنسيق
    Partner-->>Reviewer: قبول أو رفض مع السبب
  end
  Reviewer->>Permit: اعتماد أو إرجاع
  Permit->>Masar: القرار النهائي
  Masar->>Channel: نشر سجل الإغلاق
  Channel-->>Masar: إقرار
  Field->>Masar: حالة وقياسات
  Masar-->>Reviewer: انحراف عن المتوقع
  Masar->>Masar: معايرة بعد الإغلاق
```

## رحلة الحالة عالية الأثر

```mermaid
flowchart TB
  A["فحص سريع"] --> B{"هل تجاوزت الدرجة الحد؟"}
  B -- "لا" --> C["استمرار المراجعة العادية"]
  B -- "نعم" --> D["تجهيز حزمة سيناريو"]
  D --> E["تشغيل محاكاة متخصصة"]
  E --> F{"هل النتيجة مستقرة؟"}
  F -- "لا" --> G["طلب بيانات أو تعديل الخطة"]
  G --> D
  F -- "نعم" --> H["إعادة المؤشرات إلى أثر"]
  H --> I["مقارنة البدائل وشرح الفرق"]
  I --> J["قرار بشري"]
```

## رحلة النشر والقياس

```mermaid
flowchart TB
  A["اعتماد الخطة"] --> B["تحقق هندسي وزمني"]
  B --> C{"صالح للنشر؟"}
  C -- "لا" --> D["عرض الأخطاء"]
  D --> B
  C -- "نعم" --> E["إنشاء نسخة معيارية"]
  E --> F["إرسال إلى القنوات"]
  F --> G{"وصل الإقرار؟"}
  G -- "لا" --> H["إعادة ومحضر خطأ"]
  H --> F
  G -- "نعم" --> I["مراقبة الحداثة"]
  I --> J["استقبال قياس ميداني"]
  J --> K{"انحراف كبير؟"}
  K -- "نعم" --> L["تنبيه وتشغيل خطة استجابة"]
  K -- "لا" --> M["استمرار المراقبة"]
  L --> M
  M --> N["انتهاء وسحب النشر"]
  N --> O["معايرة"]
```

## شاشات المنتج

### سطح العمل

- صندوق الأعمال.
- خريطة القرار.
- ملف العمل.
- لوحة المؤشرات.

### العمل

- ملخص الطلب.
- البيانات الناقصة.
- الأثر.
- البدائل.
- التعارضات.
- فرصة التعاون.
- خطة المرور.
- سجل القرار.
- حالة النشر.
- القياس الفعلي.

### الإدارة

- قواعد التصعيد.
- قاموس الحالات.
- مصادر البيانات.
- نسخ النموذج.
- الجهات والصلاحيات.
- إعدادات النشر.

### الميدان

- مهام اليوم.
- خريطة الموقع.
- بدء وإيقاف.
- قياس الطابور والسرعة.
- صورة وملاحظة.
- إنهاء المهمة.

### الجمهور

- بحث باسم الطريق.
- الأعمال الحالية والقادمة.
- وصف مبسط.
- الجهة والمقاول.
- وقت البدء المتوقع والنهاية.
- التحويلة المعتمدة.
- وقت آخر تحديث.

## حالات الشاشة الإلزامية

لكل شاشة:

- تحميل أولي.
- لا توجد نتائج.
- بيانات قديمة.
- اتصال منقطع.
- صلاحية غير كافية.
- فشل مصدر واحد مع بقاء البقية.
- تعديل غير محفوظ.
- تعارض بين نسختين.
- إجراء ناجح.
- إجراء يحتاج متابعة.
