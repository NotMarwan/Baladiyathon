# قاموس بيانات حزمة القياس الميداني

المرجع الحاكم للحقول: `field-study.schema.json`. هذا الملف يشرح **لماذا** يوجد
كل حقل وما الذي يفسد بغيابه — والمخطط يفرض الشكل.

## قاعدة تسري على كل حقل

قيمة غائبة تُكتب فارغة أو `null`. **لا تُكتب صفراً**. الصفر في عمود الحجم يعني
«لم تمرّ مركبة»، وهو ادّعاء قياس؛ والفراغ يعني «لا نعرف». الفرق بينهما يقلب
حساب ساعات-المركبة رأساً على عقب.

## `study` — تعريف الحالة

| الحقل | الوحدة | لماذا | ما يفسد بغيابه |
|---|---|---|---|
| `studyId` | معرّف | مفتاح الحزمة | لا تُربط الملفات ببعضها |
| `permitRef` | معرّف | الربط بتصريح أثر وتوقّعه | لا مقارنة متوقَّع/مرصود |
| `timezone` | IANA | الرياض `Asia/Riyadh` بلا توقيت صيفي | إزاحة ساعة تنقل الذروة |
| `dataMode` | تصنيف | `local-field` للحقيقي، `synthetic` للمثال | يُقرأ التركيبي دليلاً |

## `closure` — الإغلاق كما وقع

| الحقل | الوحدة | لماذا |
|---|---|---|
| `actualStart` / `actualEnd` | ISO 8601 | **الفعلي لا المصرَّح به.** الفارق بينهما هو أول ما يزيح السلاسل عن نافذتها |
| `phases` | مصفوفة | إغلاق ليلي متكرر ليس إغلاقاً ممتداً. بلا مراحل تُحسب ساعات فتحٍ ضمن الإغلاق |
| `closureType` | تصنيف | إغلاق حارة يختلف عن كتف يختلف عن تبادل اتجاه |
| `lanes` / `lanesClosed` | عدد | مقام ونسبة الإغلاق |
| `direction` | نصّ | الأثر اتجاهي؛ خلط الاتجاهين يخفّف الذروة |
| `workExtentM` | متر | طول التعرّض. بلا طول لا يُنسَب التأخير إلى مسافة |

## `geometry`

| الحقل | لماذا |
|---|---|
| `affectedSegment` | المقطع المتأثر — عليه تقع سلسلتا «قبل» و«أثناء» |
| `alternates` | البدائل — عليها يُقاس أين ذهب الحمل |
| `controlCorridor` | **محور المقارنة.** بغيابه لا أثر سببي، فقط فرق مرتبط زمنياً |

## `series` — السلاسل الزمنية

أربع سلاسل: `before` و`during` و`after` و`control`.

| الحقل | الوحدة | ملاحظة |
|---|---|---|
| `intervalMinutes` | دقيقة | **معلن لا مستنتج.** سلسلة بفواصل مختلطة تقارن ساعةً بربع ساعة |
| `at` | ISO 8601 | لحظة الرصد بالمنطقة الزمنية |
| `segmentId` | معرّف | يجب أن يشترك بين «قبل» و«أثناء»، وإلا قورن مكانان لا حالتان |
| `speedKph` | كم/س | متاح من كل مزوّد حركة |
| `travelTimeSec` | ثانية | أدقّ من السرعة لقياس التأخير المباشر |
| `volumeVehPerHour` | مركبة/ساعة | **لا ينتجه أي مزوّد مسبار.** مصدره عدّاد جهة |
| `occupancyPct` | ٪ | من الكواشف الحثّية إن وُجدت |
| `sampleSize` | عدد | حجم العيّنة خلف القيمة |
| `coverage` | 0–1 | نسبة طول المقطع المغطّاة |
| `quality` | تصنيف | `ok` / `partial` / `stale` / `failed`. الفاشل يُحفظ ولا يُحذف |
| `source` | نصّ | من أنتج هذه القيمة بعينها |

### لماذا `volume` هو الحقل الحاكم

محرك أثر يخرج **ساعات-مركبة**. والقياس الميداني يعطي سرعة وزمناً. تحويل الزمن
إلى ساعات-مركبة يحتاج ضربه في عدد المركبات. فبلا عمود الحجم:

- تُقاس السرعة والتأخير الفردي: **نعم**.
- يُقارن المتوقَّع بالمرصود: **لا**.
- تُعاير معاملات النموذج: **لا**.

## `confounders` — العوامل المربكة

سجلٌّ **فارغ ليس غياباً**. الفاحص يفرّق بين «لا عوامل مسجّلة» و«لم يُسجَّل شيء»،
والثاني يخفض الثقة.

| الحقل | لماذا |
|---|---|
| `kind` | حادث · طقس · فعالية · عطلة · تغيير إشارة · أخرى |
| `affects` | المعالَج أم المقارن أم كلاهما — عاملٌ يمسّ المقارن وحده يقلب اتجاه النتيجة |
| `excluded` + `exclusionReason` | الاستبعاد يُسجَّل بسببه. استبعادٌ صامت هو انتقاء بيانات |

## `counterfactual` — تصميم المقارنة

| القيمة | القوّة | يشترط |
|---|---|---|
| `control-corridor` | قوي | هندسة المحور + سلسلة عليه في الفترتين |
| `difference-in-differences` | قوي | محور مقارنة + سلاسل الفترتين لكليهما |
| `matched-days` | متوسط | قاعدة مطابقة معلنة + سلسلة مقارنة |
| `matching` | متوسط | قاعدة ومتغيّرات المطابقة |
| `historical-period` | ضعيف–متوسط | سلسلة تاريخية على المقطع نفسه |
| `none` | — | **يمنع الادّعاء السببي** |

## `provenance`

| الحقل | لماذا |
|---|---|
| `capturedAt` / `importedAt` | الفارق بينهما يكشف تأخّر السلسلة |
| `sources[].metric` | `speed` / `travelTime` / `volume` / `occupancy` / `queue` — لكل مقياس مصدره |
| `sources[].license` | شرط الاستعمال. تخزينٌ يخالفه عيبٌ قانوني لا تقني |
| `sources[].knownLimits` | ما لا يقوله هذا المصدر — يُكتب مرة عنده لا يُستنتج كل مرة |
| `exclusions` | ما استُبعد ولماذا |
