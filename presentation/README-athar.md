# أثر — دليل التشغيل السريع

## ⚡ دليل المحكّم — 60 ثانية

1. شغّل الخادم ثم افتح `http://localhost:8734/athar-prototype.html`.
2. اضغط «حدد موقع الحفر» ثم «حسّن الجدولة».
3. اختر الجدول الأول وشاهد الأحمر يتحول أخضر والعدّادات.
4. صدّر ملف WZDx أو اضغط «أصدر خطة إدارة المرور PDF»؛ كلاهما يستخدم نوافذ الجدول المختار نفسها.

وضع API (اختياري، لخادم Node محلي بدون تبعيات): شغّل `node presentation/server.js`
ثم افتح `http://localhost:8734/athar-prototype.html`. الاختبارات: `node presentation/tests/engine-test.js`.

نموذج تفاعلي لتقييم الأثر المروري لتصاريح الحفر، وجدولة مثلى، ودمج تصاريح
(Dig-Once)، ضمن مبادرة **بلدياتثون 2026 · التحدي الثالث**.

## (أ) الوضع الثابت (بدون خادم)

افتح الملف مباشرة في المتصفح:

```
presentation/athar-prototype.html
```

يعمل النموذج بالكامل بدون اتصال بالإنترنت — بما فيه الخريطة. الطرق والمعالم
والخطوط والأيقونات كلها محلية تحت `data/` و`vendor/`، فلا يخرج أي طلب إلى
الشبكة بعد تحميل الصفحة. اختبار `worksmap-style-test.js` يمنع تسرب أي رابط
خارجي، واختبار `worksmap-wiring-test.js` يمنع تسربه من وسوم الصفحة.

## (ب) وضع الـ API (خادم محلي)

```bash
node presentation/server.js
```

ثم افتح:

```
http://localhost:8734/athar-prototype.html
```

تكتشف الصفحة الخادم تلقائيًا (فحص `fetch('/api/works')` بمهلة 800ms) وتعرض
شارة «متصل بالخادم — وضع API»، وتوجّه طلبات الدرجة/الجدولة المثلى عبر
الـ API بدلًا من حساب المحرك محليًا.

### نقاط النهاية (Endpoints)

| المسار | الطريقة | الوصف |
|---|---|---|
| `/api/score` | POST | حساب درجة الأثر المروري لإغلاق مسارات معيّن |
| `/api/optimize` | POST | أفضل 3 جداول زمنية بديلة |
| `/api/digonce` | POST | مقارنة تكلفة الحفر المنفصل مقابل الحفر المشترك |
| `/api/works` | GET | خريطة الأعمال العامة (GeoJSON) |

الخادم يعتمد فقط على مكتبات Node القياسية (`http`, `fs`, `path`) —
بلا أي تبعيات خارجية.

### عقد إدخال الحساب والجدولة

المساران `/api/score` و`/api/optimize` يتطلبان جسماً من نوع كائن JSON
يحتوي الحقول التالية:

- `aadt`: رقم منتهٍ أكبر من صفر.
- `lanes`: عدد صحيح أكبر من صفر.
- `lanesClosed`: عدد صحيح بين واحد وعدد المسارات الكلي.
- `startHour`: عدد صحيح بين صفر وثلاثة وعشرين.
- `durationHours`: رقم منتهٍ أكبر من صفر، ويسمح بالمدة الكسرية.

يستخدم الخادم القيم التوضيحية المعلنة في المحرك للحقلين
`capacityPerLane` و`freeFlowMin` إذا لم يرسلهما العميل. وإذا أرسلهما العميل
فيجب أن يكونا رقمين منتهيين أكبر من صفر.

حالات الرفض:

- `400`: صيغة JSON معطوبة أو بنية ليست كائناً.
- `413`: جسم يتجاوز ميغابايت واحداً.
- `422`: حقل ناقص أو قيمة خارج العقد، بالشكل الثابت
  `{"error":"VALIDATION_ERROR","fields":{...}}`.
- `500`: خطأ داخلي؛ لا يُحوّل إلى خطأ إدخال.

مسار `/api/digonce` يتطلب `trenchKm` موجباً و`permitsMerged` عدداً صحيحاً
موجباً. استيراد `server.js` لا يفتح منفذاً؛ الاستماع يحدث فقط عند تشغيل
الملف كنقطة دخول.

## (ج) الاختبارات

```bash
node presentation/tests/engine-test.js
node presentation/tests/ui-smoke-test.js
node presentation/tests/routing-test.js
node presentation/tests/innovation-test.js
node presentation/tests/server-test.js
```

تغطي الحزم النوافذ الجزئية، وتطابق الجدول مع التصدير والطباعة، وحفظ الحركة
المحولة، والسعة بعد التحويل، والتحقق الصارم من الطلبات، إلى جانب اختبارات
المحرك والتوجيه والابتكار السابقة.

يمثل كل بديل جدولة مصفوفة `windows`. تحتوي كل نافذة `dayOffset` و`startHour`
و`durationHours`. مجموع مدد النوافذ يساوي مدة العمل المطلوبة، ويصدر WZDx
عنصر إغلاق مستقلاً لكل نافذة مع `start_date` و`end_date`.

## (هـ) الخريطة

صفحتان تستهلكان نفس الوحدات:

| الصفحة | الدور |
|---|---|
| `athar-map.html` | **الخريطة** — صفحة مستقلة بملء الشاشة: كل الطبقات، بوب-أب التفاصيل، فرد التجميعات، دليل، مقياس رسم |
| `athar-prototype.html` | الخريطة مضمّنة داخل مسار القرار (الممر وموقع الحفر والبدائل) |

`athar-worksmap.js` — خريطة الأعمال بلغة one.network البصرية فوق بيانات محلية:
ثلاثية `casing/line/symbol` لكل نوع، خطوط متقطعة تتبع محور الشارع، تجميع
للنقاط، ولوحة فترة زمنية وطبقات.

| الملف | المسؤولية |
|---|---|
| `athar-worksmap-style.js` | الخريطة الأساسية الفاتحة من GeoJSON محلي |
| `athar-worksmap-layers.js` | الثلاثية + التجميع + الفلاتر |
| `athar-worksmap-data.js` | تطبيع `works.geojson` إلى مخطط الرسم |
| `athar-worksmap-panel.js` | لوحة الفترة الزمنية وإظهار الطبقات |
| `athar-worksmap.js` | التهيئة وعقد الـ API الذي يستهلكه النموذج |
| `athar-worksmap-interactions.js` | بوب-أب التفاصيل وفرد التجميعات (صفحة الخريطة) |
| `athar-worksmap-page.css` | تنسيق صفحة الخريطة المستقلة |

**الهندسة تتبع الإسفلت.** خط الأعمال المرسوم يدوياً يقطع الأحياء ويبدو عشوائياً،
فكل ميزة تُثبَّت على مقطع من محور شارع مسمّى مأخوذ من `riyadh-roads.geojson`.
والممر نفسه مبني من محور طريق الملك فهد لا من ست نقاط مستقيمة.

**إعادة بناء الأصول والهندسة** (بعد تغيير الأيقونات أو النطاق أو مواضع الأعمال):

```bash
node scripts/build-sprite.js            # يحتاج: npm install --no-save sharp
node scripts/fetch-glyphs.js            # مرة واحدة (شبكة)
node scripts/fetch-rtl-plugin.js        # مرة واحدة (شبكة)
node scripts/fetch-base-layers.js       # مرة واحدة (شبكة · Overpass)
node scripts/snap-works-to-roads.js     # محلي — يثبّت الأعمال على المحاور
node scripts/build-corridor-geometry.js # محلي — يبني هندسة الممر
```

**إضافة RTL مثبَّتة على 0.2.3 عن قصد.** الإصدار 0.4.0 مبني على WebAssembly
ويفشل استيراده داخل عامل MapLibre، فتظهر العربية حروفاً منفصلة معكوسة. اختبار
`worksmap-assets-test.js` يرفض بناء WebAssembly.

## ملاحظة مصادر البيانات

كل رقم واقعي معروض في الواجهة أو العرض يحمل مصدرًا من سجل المصادر
(Sources Ledger). أي مُدخل تجريبي (مثل حجم المرور الافتراضي) يُعلَّم
بوضوح بعبارة «بيانات توضيحية للعرض».

توزيع الحركة المحولة على البدائل قاعدة توضيحية تعتمد على الزمن النسبي
ومجموع حصصها واحد؛ ليست سلوكاً مقاساً. النموذج محلي توضيحي، ولا يمثل
تكاملاً منفذاً مع نظام تصاريح حكومي أو بيانات حركة حية مضمونة.
